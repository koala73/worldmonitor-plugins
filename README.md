# World Monitor plugins

Plugins that connect AI assistants to [World Monitor](https://www.worldmonitor.app), a real-time global intelligence service for geopolitics, conflict, country risk, shipping, natural hazards, energy and markets.

| Folder | Plugin |
|---|---|
| [`claude-plugin/`](claude-plugin/) | Claude plugin: the World Monitor MCP connector plus six source-backed workflow skills |

**This repository is a mirror.** The plugins are developed and tested in [koala73/worldmonitor](https://github.com/koala73/worldmonitor), and a workflow there copies each folder here on every change to `main`. Open issues and pull requests in the main repository.
